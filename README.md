# Sistema Academia

Sistema desktop em Java (Swing, JDBC e MySQL) para gerenciar alunos, instrutores, modalidades, planos e matriculas de uma academia.

## Como executar
1. Inicie o MySQL pelo XAMPP e importe database/academia.sql no phpMyAdmin.
2. Abra o projeto no NetBeans.
3. Execute TestCon.java para testar a conexao com o banco.
